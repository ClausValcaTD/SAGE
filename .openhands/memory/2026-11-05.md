# 2026-11-05 — 3D layer compositing

Task: bring Model 2B polygons into the visible 3D layer for Dead or Alive.

Root causes found:
1. geometry.cpp bottom clip plane operands reversed (viewport-center vs
   center-viewport). Fixed one line → 3D buffer populated.
2. video.cpp tile passes ignored the System 24 screen-space priority mask at
   tile RAM 0x6000. Implemented `pri_bit != sprite_pass` skip and made `opaque`
   false on the sprite pass.
3. bus.cpp didn't route the H/V sync writes (0x01040000/0x01060000) to the video
   CRTC offsets, so polygons projected off-screen.

Dead ends: tile-word bit-15 category split (hid the 3D), opaque-flag change for
layers >= 2, SAGE_NO_PASS1, restricting pass 2 to foreground layers. All
rejected. The mask model is the one that matches MAME and works.

Verification: frame==3D 23233/23233 @1200, 18938/18938 @2000. bbox y 65..424.

Diagnostic env vars used (since removed from source): SAGE_GEO_DBG, SAGE_MASKDBG,
SAGE_CAT, SAGE_NO_PASS1, SAGE_PASS1_LOW. Remaining: SAGE_HEADLESS, SAGE_PPM,
SAGE_PPM3D, SAGE_RAWVIDEO, SAGE_DUMPRAW, SAGE_TRACE.

Committed on branch fix/3d-layer-compositing (981f882).

## Milestone 7 — Sega SCSP sound board (68EC000 + YMF292)

Task: add the Model 2 sound subsystem (sound CPU, SCSP, host serial link).

What was built:
- `third_party/musashi/` — Musashi v4.60 (Karl Stenerud, MIT), 68000-only
  (M68K_EMULATE_010/EC020/020/030/040 and PMMU all OFF in `m68kconf.h`).
- `include/sage/cpu/m68000.h` + `src/cpu/m68000.cpp` — `cpu::M68000` wraps
  Musashi behind a `Bus68k` callback interface. Musashi's memory callbacks are
  **process-global**; SAGE has one sound CPU, so a single `g_bus` pointer is
  installed for the instance's lifetime.
- `include/sage/hw/compat.h` — MAME-style shims (u8..s64/usize, bit/bits,
  sign_extend, f2u/u2f, a no-op `Archive`, `SM2_WARN`/`SM2_TRACE` gated by
  `SAGE_SOUND_LOG`). The `format(printf)` attribute is guarded for MSVC.
- `include/sage/hw/scsp.h` + `src/hw/scsp.cpp` (1850 lines) and
  `scsp_dsp.{h,cpp}` — ported nearly verbatim from the sm2-emu/MAME reference.
- `include/sage/hw/i8251.h` + `src/hw/i8251.cpp` — UART.
- `include/sage/hw/sound_board.h` + `src/hw/sound_board.cpp` — `hw::SoundBoard`
  (68EC000 + SCSP + 512 KB shared RAM + sample ROM).

Key facts:
- **Musashi opcodes are generated, not committed.** `m68kmake` is built as a
  host tool and run via `add_custom_command` into `${CMAKE_BINARY_DIR}/musashi`.
  `softfloat/softfloat.c` must be linked even though the 68000 has no FPU —
  `m68kcpu.c` pulls in `m68kfpu.c`, which references the softfloat symbols.
  Build the whole `musashi` lib with `-w` (third-party C).
- Sound board memory map (MAME `model2_snd`): RAM 0x000000–0x07ffff (shared with
  SCSP), SCSP regs 0x100000–0x100fff, bank ctrl 0x400000 (write-only, inert for
  DOA — guarded by `m_samples.size() <= 0x800000`), program ROM
  0x600000–0x67ffff, samples 0x800000+, banked windows 0xa00000/0xe00000.
- **Clock ratios kept exact**: 68000 = host×7056/15625 (45.1584 MHz/4 over
  25 MHz), SCSP = 22.5792 MHz/512 = 44100 Hz; one sample == 256 68000 cycles.
  Remainder carried in `m_cycle_debt` between `run()` calls.
- **Host serial link**: i8251 at `0x009c0000` with `umask32(0x000000ff)`, so
  data is at +0 and status at +4 (one dword apart, NOT the 2A/2C stride). Only
  byte lane 0 is connected. tx→`SCSP::midi_in`, SCSP midi-out→`write_rxd`,
  ready→`Bus::sound_ready_w()`. The ready handler is **level-based** (not
  edge-triggered); the sound IRQ is **bit 10** (`1u<<10`) of intreq/intena.
  `sound_ready_w` asserts when `txrdy() || rxrdy()` and the line is enabled.
- Bus read/write for the UART uses `(addr - kUartBase) >> 2` as the register
  index (0=data, 1=status), matching MAME's handler offset.
- `Bus::attach(roms, game)` now takes the set name so `configure_balance` is
  not hardcoded; DOA's flat SCSP gain is 500/256.

Verification:
- 3600-frame headless run: 68EC000 running from ROM (PC in 0x60xxxx), SCSP
  produced 2.6M samples with 1099 slot starts and peak 17080, 3.1M polygons
  rendered. `SAGE_WAV` dump analysed: silence / blip at t=3s / loud passage at
  t=9s (peak 7917) — structured audio, not noise.
- **Video is byte-identical to the pre-change baseline** (`cmp` on 300 frames
  of `SAGE_RAWVIDEO`) — the sound board does not perturb the main CPU.
- Clean build from scratch: 0 errors, 0 warnings from new code (only pre-existing
  miniz/geometry/sharc warnings remain).

Perf: ~45 s wall for 600 frames (10 s emulated) headless — the per-instruction
`tick_sound` is the cost. Acceptable for development; batch at frame boundaries
if it ever needs to be faster.

Committed on branch feat/scsp-sound-board (cfe16a8). Not pushed.
