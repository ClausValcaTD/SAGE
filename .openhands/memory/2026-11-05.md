# 2026-11-05 — 3D layer compositing

Task: bring Model 2B polygons into the visible 3D layer for Dead or Alive.

Root causes found:
1. geometry.cpp bottom clip plane operands reversed (viewport-center vs
   center-viewport). Fixed one line → 3D buffer populated.
2. video.cpp tile passes ignored the System 24 screen-space priority mask at
   tile RAM 0x6000. Implemented `pri_bit != sprite_pass` skip and made `opaque`
   false on the sprite pass.
3. bus.cpp didn't route the H/V sync writes (0x01040000/0x01060000) to the video
   CRTC offsets, so polygons projected off-screen.

Dead ends: tile-word bit-15 category split (hid the 3D), opaque-flag change for
layers >= 2, SAGE_NO_PASS1, restricting pass 2 to foreground layers. All
rejected. The mask model is the one that matches MAME and works.

Verification: frame==3D 23233/23233 @1200, 18938/18938 @2000. bbox y 65..424.

Diagnostic env vars used (since removed from source): SAGE_GEO_DBG, SAGE_MASKDBG,
SAGE_CAT, SAGE_NO_PASS1, SAGE_PASS1_LOW. Remaining: SAGE_HEADLESS, SAGE_PPM,
SAGE_PPM3D, SAGE_RAWVIDEO, SAGE_DUMPRAW, SAGE_TRACE.
